Personal backup utility

SSD Google Drive Backup

A local utility that synchronizes a personally selected external SSD folder to the owner's Google Drive.

Purpose

This application is for the owner's personal use. It runs locally on a Mac and uses rclone with the Google Drive API to maintain a one-way cloud copy of selected files.

New and changed files are uploaded. Files removed from the source are removed from the corresponding cloud destination; Drive deletions are configured to use Trash. It is a synchronization tool, not a historical archive.

Google Drive access

The owner authorizes the application through Google's OAuth consent screen. Drive access is used to list and compare destination files, create folders, upload files, update files, and remove files within the selected backup destination.

File contents are read from the external SSD and sent directly to Google over HTTPS. The utility does not create a complete second local copy through the Google Drive desktop mounted folder.

Local operation

Credentials, authorization tokens, and diagnostic logs are stored locally on the owner's Mac. Scheduled synchronization checks that the expected SSD is connected before running.

This website only provides application information. It does not accept uploads, host backups, or provide a public sign-in service.

Information and contact

See the Privacy Policy for data handling details. For questions about this personal utility, contact its maintainer through the project issue tracker. Do not post credentials or private files there.

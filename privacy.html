SSD Google Drive Backup

Privacy Policy

Effective date: October 12, 2026

Scope

SSD Google Drive Backup is a personal utility operated by its owner on the owner's Mac. This policy describes the utility's use of Google Drive data and this informational website.

Data accessed and used

The utility reads selected local file contents and metadata, including names, folder paths, sizes and modification times. It reads corresponding Google Drive metadata and checksums to compare local and cloud files and verify transfers. The Google account email address may be read during setup to confirm the correct account.

Google OAuth credentials and tokens are used to authenticate API requests. These credentials are not published on this website.

Purpose and permissions

Data is used only to synchronize the owner's selected files to the owner's selected Drive destination, verify transfers, and diagnose synchronization problems. The configured synchronization is one-way from the local source to Drive. Google consent may grant broader Drive access than the selected folder; the local synchronization job is configured to use a fixed destination folder.

Storage, transfer and sharing

Files are transmitted directly from the owner's computer to Google through encrypted HTTPS connections and stored in the owner's Google Drive. Credentials and tokens are stored in a local account-restricted configuration directory. Local diagnostic logs may include file names, paths, transfer status, and errors.

The utility does not send backup contents to a separate application server, sell data, use data for advertising, or use Google user data to train AI models. Google handles data on its service under its own Privacy Policy.

Retention and control

The owner controls local files and the cloud backup. Deleted source files can be removed from the synchronization destination, with Drive deletions configured to go to Trash. Google's trash and file-version retention rules apply. Disabling the utility does not automatically delete existing cloud files.

The owner can stop the local scheduled job and revoke the application's authorization in Google account connections. Revocation prevents future authorized API access; existing local credentials and logs can be removed separately by the owner.

This website

This is a static information site hosted by GitHub Pages. It has no sign-in, upload form, advertising, or application analytics scripts. GitHub may process ordinary web request information as the hosting provider, under the GitHub Privacy Statement.

Contact and updates

Contact the maintainer through the project issue tracker. Do not post tokens, credentials or private backup contents. Changes to this policy will be published here with an updated effective date.
